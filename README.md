# AI Chatbot Internship Assignments

This repository contains all six AI Chatbot Internship tasks completed using Python, Streamlit, Google Gemini API, and other AI technologies.

## 📂 Project Structure

```
AI-Chatbot-Assignments
│
├── Task-1_Sentiment_Chatbot
├── Task-2_Medical_QA_Chatbot
├── Task-3_Research_Chatbot
├── Task-4_Dynamic_RAG_Chatbot
├── Task-5_Multimodal_Chatbot
├── Task-6_Multilingual_Chatbot
```

## 🚀 Tasks Completed

### Task 1 – Sentiment Analysis Chatbot
- Built a chatbot to classify text sentiment.
- Technologies: Python, NLTK, Streamlit.

### Task 2 – Medical Q&A Chatbot
- Medical question-answering chatbot using a medical dataset.
- Technologies: Python, Streamlit.

### Task 3 – Research Chatbot
- Research paper search and explanation chatbot.
- Technologies: Python, Streamlit, Ollama.

### Task 4 – Dynamic RAG Chatbot
- Retrieval-Augmented Generation chatbot with dynamic knowledge updates.
- Technologies: Python, Vector Database, Streamlit.

### Task 5 – Multimodal Chatbot
- Supports text conversations and image understanding using Gemini AI.
- Technologies: Google Gemini API, Streamlit, Pillow.

### Task 6 – Multilingual Chatbot
- Automatic language detection.
- Supports English, Hindi, French, and Spanish.
- Responds in the user's language.
- Technologies: Google Gemini API, LangDetect, Streamlit.

## 🛠 Technologies Used

- Python
- Streamlit

- LangDetect

- Git & GitHub

## ▶️ How to Run

1. Clone the repository.
2. Navigate to the required task folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Create a `.env` file (if required):

```env
GEMINI_API_KEY=YOUR_API_KEY
```

5. Run the project:

```bash
streamlit run app.py
```
