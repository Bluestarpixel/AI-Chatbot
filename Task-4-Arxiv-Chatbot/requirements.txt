# 📚 ArXiv Research Chatbot

An AI-powered research assistant built using **Streamlit**, **Python**, and the **arXiv Computer Science dataset**. The chatbot allows users to search research papers, generate summaries, and receive AI-powered explanations of complex research concepts using the open-source **Phi-3 Mini** language model via **Ollama**.

---

## 📌 Features

- 🔍 Search Computer Science research papers from the arXiv dataset
- 📄 Display paper title, categories, and abstract
- 📝 Automatic research paper summarization
- 🤖 AI-powered explanation using Phi-3 Mini (Open Source LLM)
- 💬 Interactive Streamlit web interface
- ⚡ Fast and lightweight implementation

## ⚙ Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/arxiv-research-chatbot.git
cd arxiv-research-chatbot
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate virtual environment

Windows

```bash
venv\Scripts\activate
```

Linux/Mac

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

---

## 🤖 Install Ollama

Download Ollama from:

https://ollama.com/download

Pull the Phi-3 Mini model:

```bash
ollama pull phi3:mini
```

Verify installation:

```bash
ollama run phi3:mini
```

---

## ▶ Running the Application

```bash
streamlit run app.py
```

The application will open in your browser at

```
http://localhost:8501
```

## 🚀 How It Works

1. User enters a research topic.
2. The chatbot searches the Computer Science papers.
3. Relevant papers are displayed.
4. Abstracts are summarized automatically.
5. Phi-3 Mini generates a simplified explanation of the research paper.
